# Design system

The rendered Research opening is the canonical reference. If this document and the reference render differ, use the reference render.

## Grid

| Viewport | Columns | Outer margin | Gutter |
| --- | ---: | ---: | ---: |
| 1200 px and above | 12 | 64 px | 24 px |
| 768–1199 px | 8 | 32 px | 24 px |
| Below 768 px | 4 | 24 px | 16 px |

Content width is capped at 1312 px. Elements occupy named grid columns; no percentage offsets or page-specific substitute grids.

## Type

- Scientific prose and ordinary headings: STIX Two Text.
- Navigation, labels, captions, citations, metadata and controls: IBM Plex Sans.
- Body: 19 px / 1.5 desktop; 18 px mobile.
- Intellectual proposition: 36 px / 1.15.
- Opening reflection: 24.5 px / 1.4.
- Major research heading: 28 px / 1.25.
- Ordinary heading: 23 px / 1.3.
- Archive title: 22 px / 1.3.
- Label: 12 px / 16 px, uppercase, 0.08 em tracking.
- Caption and metadata: 12 px / 1.6.
- Citation/action line: 12–13 px / 24 px.

Text blocks follow the grid widths in the canonical Research opening. Prose is not expanded to fill unused columns.

## Spacing

Only use: 8, 16, 24, 32, 48, 64 and 96 px.

The paired current questions use a 48 px vertical stagger on desktop. Mobile removes the stagger.

## Colour and rules

- Ground: #ffffff.
- Text: #1d2b30.
- Functional links and status: #386860.
- Rules: #d8ddd9.
- Scientific/documentary plate: #f7f7f2.
- Rule weight: 1 px.

Colour from scientific figures, artwork, books and authentic project marks is retained. No additional accent colour is introduced.

## Metadata

Marginal metadata uses 12 px IBM Plex Sans with tabular numerals. A record places year/status in the marginal field before its main title or argument. Citations use the same family and size and sit below the object or in the designated metadata field.

## Images

- Primary scientific plate: 8–9 columns.
- Secondary scientific object: 5–6 columns.
- Documentary object: 2–4 columns.
- Portrait: 4–5 columns, complete and uncropped.

Figures remain evidence. Captions identify the object, source and paper without repeating the section prose.

## Links

Links use teal, a 1 px underline and a 4 px underline offset. Hover increases the underline to 2 px. Focus uses a 2 px teal outline with 4 px offset. Archive action groups use a full 24 px horizontal spacing token.

## Header and footer

Header and footer use the master frame and grid. The header has 24 px vertical padding and a 1 px lower rule. The site name occupies columns 1–3; primary navigation occupies columns 6–12 and is right aligned. Mobile shows a Menu button in column 4 and expands the six primary links below it.

The footer has a 1 px upper rule and 24 px vertical padding. The name occupies columns 1–3. Scholarly links occupy columns 7–12 and are right aligned; on mobile they move below the name and align left.

## Registers

- Folio: Home, About, Writing, COIN.
- Scientific: Research, Selected Contributions.
- Archive: Publications, Software, People.

The grid, type, rules, metadata and links are shared. Density and image occupation change with the content.
